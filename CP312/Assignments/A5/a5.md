    ### Graph and Start Vertex

    ```
        A
       /|\
      1 2 3
     /  |  \
    B   C   D
    |   |   |
    6   7   8
     \  |  /
       \|/
        E
    ```
    **Edges:** (A,B)=1, (A,C)=2, (A,D)=3, (B,E)=6, (C,E)=7, (D,E)=8
    **Start vertex:** A

    **MST:** Edges {(A,B), (A,C), (A,D), (B,E)} with weight = 1+2+3+6 = 12

    - explore along one branch before backtracking
    - if ordered A->B->E, then backtrack: add (D,E)=8, (A,C)=2, (A,B)=1
    - total weight is 14 != 12
    - DFS is not MST

    With an appropriate adjacency list order, neither BFS or DFS produces the MST from vertext A.

2.  \[6 marks\] Prove or disprove each of the following statements,
    where in each case $G = (V,E)$ is a connected undirected weighted
    graph with $n$ vertices and $m$ edges.

    1.  If all weights of edges in $G$ are distinct then the lightest
        edge $e$ is part of every minimum spanning tree of G.

    2.  If all weights of edges in $G$ are distinct then the heaviest
        edge $e$ is not part of any minimum spanning tree of $G$.

    3.  If $e$ is a maximal weight edge of a cycle of $G$, then there is
        a minimum spanning tree of $G$ that does not include $e$.

    ### part (a): Lightest edge in every MST

    **Statment:** If all weights are distinct, the lightest edge e is in every MST

    **Answer:** true

    **Proof:** Let e=(u,v) be the minimum weight edge. Consider cut (S, V\S) with u∈S, v∈V\S. By the property, in some MST the minimum edge is crossing any cut. Since e is a global minimum, every MST has e. Suppose MST T excludes e. Then T has edge e' crossing this cut with w(e') > w(e). e gives a lighter tree by replacing e', which contradictes T being a MST.

    ### part (b): Heaviest edge is no MST
    
    **Statement:** If all weigts are distinct, the heaviest edge e is not in any MST

    **Answer:** false

    **Counterexample:**
    ```
    B---C---D
      1   5
    ```
    Only edges: (B,C)=1, (C,D)=5. The MST include boh edges. (C,D)=5 is essential for connectivity because it is the heaviest edge.

    ### part (c): Maximum weight edge in cycle
    
    **Statement:** If e is a maximu weight of a cycle, there exists an MST without e

    **Answer:** true

    **Proof:** By Cycle Property, the maximum weight edge in any cycle with distinct weights is not in any MST.

Since C exists, there is a alternative edge e' connecting T1 and T2 with w(e') < w(e). Then T' = T - {e} + {e'} is a lighter spanning tree, contradicting T being a MST. Therefore, no MST contains e.

    ```
        visited = null

        DFS-Visit(v):
            visited.add(v)
    ```

4.  \[4 marks\] Consider a BFS and DFS of a connected undirected graph
    $G$ that start from the same vertex $s$. If both sets of tree-edges
    (BFS-tree and DFS-tree) are equal to each other, then $G$ is a tree.
    Prove or disprove.\

    **Statement:** If BFS and DFS from s have equal tree-edge sets, then G is a tree.

    **Answer:** True

    ### Proof
    Both BFS and DFS produce spanning trees with n-1 edges. Given T_BFS = T_DFS.

    **Key Observations:** If G has a cycle, it contains more than n-1 edges. These extra edges would be non-tree edges, classified differently by BFS vs DFS.
    Since T_BFS = T_DFS, both algorithms classify every edge identicallyy. This only happens when:
    - G has exactly n-1 edges
    - all edges are tree edges
    - no cycle exists

    Therefore G is a tree since |E| = n-1 and G is connected.

5.  \[9 marks\] A *vertex-and-edge-weighted graph* is an undirected
    graph $G = (V,E)$ where each vertex $v \in V$ has a *cost* $c(v)$
    and every edge $e \in E$ has a *weight* $w(e)$. The *length* of a
    path in $G$ is the sum of the weights of the edges in the path *and*
    the cost of the vertices in the path. In the Single-Source Shortest
    Path (SSSP) problem on vertex-and-edge-weighted graphs, we are given
    $G$ and a source vertex $s$ and we want to determine the minimum
    length of a path from $s$ to $v$ for every $v \in V$. (Note that the
    minimum length of a path from $s$ to $s$ is $c(s)$.)

    Solve the SSSP problem on vertex-and-edge-weighted graphs in the
    special case where all the weights and the costs are positive
    integers. Provide pseudo-code along with justification of the
    correctness and analyze running time complexity of your algorithm.\

    ### Main Idea
    Modify the Dijkstra algorithm to include vertex costs when entering each vertex: dist[s] = c(s), and relaxtation adds both weight and destination vertex cost.

    ### Psuedocode
    ```
    VertexEdgeDijkstra(G, s, c, w):
        \\ c[v] = vertex costs, w[e] = edge weights
        for each v ∈ V:
            dist[v] = inf
        dist[s] = c[s]

        PQ = MinHeap with (C[s], s)
        visited = null
        while PQ is not empty:
            (d,u) = PQ.extractMin()

            if u ∈ visited:
                continue
            visited.add(u)

            for each edge (u,v) ∈ E:
                if v !∈ visited:
                    newDist = dist[u] + w[(u,v)] + c[v]
                    if newDist < dist[v]:
                        dist[v] = newDist
                        PQ.insert(newDist, v)
        return dist
    ```

    ### Correctness
    The path length from s to v = sum of all vertex costs on path + sum of all edge weights.
    The algorithm maintains: dist[u] = shotest path length from s to u for all processed verticies.

    **Optimal substructure holds:** Shortest path to v through u uses shortest path to u, plus edge (u,v), plus vertex cost c[v].
    Since all cost and weights are positive and greedy selection extracting the minimum from PQ is safe. Standard Dijkstra correctness argument applies.

    ### Time Complexity
    - With Binary heap: O((|V| + |E|) log |V|)
    - With Fibonacci heap: O(|V| log |V| + |E|)
